# 执行计划 007：部署与首版验收

- 状态：待开始
- 前置：计划 001–006 的交付物和验证记录
- 目标：在用户的 Windows 主机部署真实站点，并完成首版端到端验收。
- 依据：[SPEC §3、§6–§8](../../../SPEC.md)、[系统架构](../../../ARCHITECTURE.md)、[技术方案](../../design-docs/tech-stack.md)

## 步骤

- [ ] 在获准部署时，用真实 Web 服务替换 001 的临时服务，配置 Windows 主机的应用与文件后端自启，保持文件后端仅本机可达。对照 SPEC §8 与架构图，区分浏览器到 VPS 和 frp 内部链路，在配置与 README 中写明实际协议和配置方式。
- [ ] 重启主机，验证应用与隧道恢复。从外网桌面打开站点并登录，检查未登录时无法通过直达地址访问文件、设置、预设动作或下载 `.rdp`。
- [ ] 按下方清单从外网桌面和实际手机逐项验收。记录测试日期、环境、结果和失败现象；修正首版范围内的问题后回归。
- [ ] 补齐 README 中从干净环境安装所需的依赖、配置、自启、凭据保管、最小安全配置和公网 HTTP 风险说明。依据实测结果同步详细版及精简版用户手册，复核文档链接和命令。

## 验收清单

- [ ] SPEC §6.1：外网桌面浏览器打开站点并登录。
- [ ] SPEC §6.2：浏览全盘目录，在测试目录完成上传、下载、重命名、删除和新建文件夹。
- [ ] SPEC §6.3：在浏览器预览图片、文本和视频。
- [ ] SPEC §6.4、§8.5：外网数 GB 文件上传、下载均能中断后恢复；记录实测吞吐并核对校验和。
- [ ] SPEC §6.5：外网电脑打开网页下载的 `.rdp`，成功连接目标主机。
- [ ] SPEC §6.6：登录后触发已配置的预设动作；无预设时默认进入远程桌面。
- [ ] SPEC §6.7：手机浏览器经外网将文件上传到 Windows 主机并核对内容。
- [ ] SPEC §4.3：具备前提的设备可从浏览器唤起 VS Code (WSL)。

## 完成标准

所有验收项通过，部署记录和三份面向使用者的文档与实际行为一致。将本计划和前置计划的最终状态同步到路线图。
