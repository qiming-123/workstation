# 执行计划 004：文件管理、预览与续传

- 状态：待开始
- 前置：计划 002 确定文件后端，计划 003 提供 Web 入口和认证
- 目标：完成桌面和手机浏览器的文件功能，验证数 GB 文件传输可中断恢复。
- 依据：[SPEC §4.1、§6、§8](../../../SPEC.md)、[技术方案 §4](../../design-docs/tech-stack.md)、[Web Demo](../../../demos/index.html)

## 步骤

- [ ] 把文件后端接入 003 的认证入口。通过文件页浏览 Windows 可访问的磁盘和目录，提供上传、下载、重命名、删除和新建文件夹。验证根目录导航、中文和空格文件名、名称冲突、权限不足及未登录直达文件地址；写操作使用测试文件。
- [ ] 接入图片、文本和视频的网页预览。用三种样本实测内容显示，并验证视频拖动进度条、文件不可读时的界面提示及预览直达地址的会话校验。
- [ ] 接入上传、下载的断点续传。经应用入口分别上传和下载数 GB 的同一测试文件，各主动中断一次并恢复。记录恢复位置，核对传输后文件大小和 SHA-256。
- [ ] 在窄屏浏览器验证文件选择与上传。若已有可供手机访问的测试入口，再用实际手机登录和上传，在 Windows 主机核对文件名、内容和位置。同步两份手册中已验证的文件操作步骤与可用状态。

## 完成标准

经认证的本机服务通过文件操作、三类预览、窄屏上传和数 GB 双向续传测试。实际手机从外网访问和上传，以及公网吞吐与中断恢复，由 007 做最终验收。
