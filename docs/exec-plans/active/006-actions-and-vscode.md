# 执行计划 006：预设动作与 VS Code (WSL)

- 状态：待开始
- 前置：计划 003 的认证和页面框架；计划 005 的远程桌面入口用于最终回退联调
- 目标：支持配置并触发主机预设动作，以及在浏览器所在设备唤起 VS Code。
- 依据：[SPEC §4.2–§4.3、§6、§8](../../../SPEC.md)、[技术方案 §1、§4](../../design-docs/tech-stack.md)、[Web Demo](../../../demos/index.html)

## 步骤

- [ ] 用本地 JSON 配置保存预设动作，在「设置」页提供增删与回显。重启服务后验证配置仍可读，删除动作后刷新确认不再显示，写入失败时保留原配置并提示失败。
- [ ] 在「连接」页按预设标识触发主机动作。验证已保存动作可以执行，未登录、未知或已删除的标识会被拒绝，触发请求无法覆盖预设动作内容。实测至少一个 Windows 主机动作，包括规格所举的 WSL2 中打开 VS Code 的场景。
- [ ] 验证浏览器所在设备上的 VS Code WSL 深链，确认发行版和路径指向预期目标，再接入「VS Code (WSL)」入口。分别核对主机动作和当前设备唤起发生在哪台机器，并在手册写明客户端前提。
- [ ] 清空预设动作后，从「连接」进入计划 005 的远程桌面入口并完成联调。同步两份手册的设置、连接和 VS Code 步骤。

## 完成标准

登录用户可以配置、保存并触发预设动作；清空预设后默认进入远程桌面；在具备前提的客户端，点击 VS Code 入口可实际打开预期的 WSL 目标。
