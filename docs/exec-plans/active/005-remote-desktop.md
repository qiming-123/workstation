# 执行计划 005：远程桌面连接

- 状态：待开始
- 前置：计划 001 的公网隧道可用，计划 003 提供认证，Windows 主机已确认具备远程桌面被控条件
- 目标：登录后可按需下载 `.rdp`，在外网电脑的远程桌面客户端中连到 Windows 主机。
- 依据：[SPEC §4.2、§6、§8](../../../SPEC.md)、[技术方案 §4](../../design-docs/tech-stack.md)

## 步骤

- [ ] 在现有 frp 约束下验证外网客户端到 Windows 主机的实际连接路径，保持 3389 无常驻公网映射。记录访问端和主机端的前提、会话结束后的恢复状态；若现有方案无法同时满足外网连接和端口约束，记录差异并提交用户决定。
- [ ] 实现登录后的 `.rdp` 按需下载，用已验证连接路径生成配置，不在文件内嵌登录凭据。验证无会话或篡改会话时无法下载，连接配置缺失时界面显示明确错误。
- [ ] 在「连接」页接入远程桌面入口，在另一台外网电脑下载文件并打开，验证实际出现目标 Windows 桌面。核对连接结束后仍符合端口约束。
- [ ] 将实测前提和操作同步到详细版、精简版手册，并把远程桌面入口交给计划 006 用于默认回退。

## 完成标准

外网电脑从真实站点登录、下载、打开 `.rdp` 后成功连接到目标主机；留下客户端前提和外网连通记录。
