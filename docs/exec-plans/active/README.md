| 计划 | 当前状态 | 前置计划 | 完成后可验证的结果 |
|---|---|---|---|
| [001 公网隧道](001-vps-frp-tunnel.md) | 进行中，等待用户购买 VPS | 无 | 外网可通过 frp 访问临时测试服务，重启后隧道恢复 |
| [002 文件后端最小验证](../completed/002-file-backend-validation.md) | 已完成 | 无 | Windows 本地认证代理、小文件管理与预览通过，保留 copyparty |
| [003 Web 服务与认证](../completed/003-web-authentication.md) | 已完成 | 002 | Windows 本地站点登录、退出和窄屏导航通过，功能请求共用会话校验 |
| [004 文件管理与传输](../completed/004-file-management.md) | 已完成 | 002、003 | Windows 本地文件、窄屏上传、三类预览和 2 GiB 双向续传通过 |
| [005 远程桌面](005-remote-desktop.md) | 待开始 | 001、003 | 登录后下载的 `.rdp` 能从外网连到 Windows 主机 |

| [007 部署与首版验收](007-deployment-and-acceptance.md) | 待开始 | 001–006 | 真实站点对照需求逐项通过验收，部署说明与两版手册可用 |
