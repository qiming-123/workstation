# workstation 用户手册（详细版）

当前可预览[网页版界面](../../demos/index.html)。在本地双击 HTML 文件，用浏览器打开即可。登录和文件等操作使用演示数据。以下操作说明对应[首版功能规格](../../SPEC.md)，实际使用需等待正式服务部署。

## 登录

在电脑或手机浏览器中打开已部署的 workstation 地址，使用部署时设置的账号和密码登录。文件、电脑和应用的入口在登录后可用。

## 管理电脑文件

1. 进入「文件」，打开目标磁盘和目录。这里浏览的是运行 workstation 的 Windows 主机上的文件。
2. 上传时先进入保存目录，再选择「上传」并挑选文件。把手机文件传到电脑时，可在手机浏览器中登录后按相同步骤操作。
3. 选中文件后，可下载、重命名或删除。在当前目录可新建文件夹。
4. 打开图片、文本或视频文件，可在网页中预览。

## 连接自己的电脑

在电脑浏览器中进入「连接」，选择「远程桌面」，下载 `.rdp` 文件，然后用当前电脑的远程桌面客户端打开它。

常用动作可以先在「设置」中配置，再从「连接」页面触发。例如，可以配置一个在主机的 WSL2 中打开 VS Code 的动作。没有配置预设动作时，连接入口默认指向远程桌面。

## 在当前设备打开 VS Code

当前设备已安装 VS Code 时，可在「连接」页面选择「VS Code (WSL)」。如果浏览器询问是否打开外部应用，确认后会唤起当前设备上的 VS Code。
