# workstation 用户手册（详细版）

Windows 主机启动本地服务后，可使用登录、文件管理、主机预设动作和 VS Code (WSL) 入口。远程桌面和公网访问仍在准备中。界面预览和本地启动步骤分别见 [网页版演示](../../demos/index.html)和[本地启动](../exec-plans/completed/003-web-authentication.md)。

## 登录

在浏览器打开 workstation 地址，输入部署者创建的账号和密码。本机默认地址为 `http://127.0.0.1:32100`。使用完毕后，点击「退出登录」结束会话。

## 管理电脑文件

1. 进入「文件」，在文件面板打开 Windows 主机上的目标磁盘和目录。
2. 选中文件后，可下载、重命名或删除。在当前目录可新建文件夹。
3. 点击图片、文本或视频的文件名可在浏览器中预览。
4. 上传前先打开保存目录。小文件可用基本上传，需要断点续传时选择 Up2k 上传。中断后，在同一目录重新选择原文件即可恢复。下载中断时，用支持断点续传的客户端恢复下载。同一面板可用于窄屏，实际手机从公网访问待部署后验收。

## 连接自己的电脑

主机须安装 Windows 版 VS Code、WSL 扩展和目标发行版，并在本机配置中填写 `vscodePath`。在「设置」的「主机预设动作」中填写名称、发行版和 WSL 文件夹路径，添加后回到「连接」触发。VS Code 将从部署 workstation 的 Windows 主机打开。

没有预设动作时，「连接」默认显示远程桌面入口。实际 `.rdp` 下载和连接待计划 005 接入。

## 在当前设备打开 VS Code

当前设备须安装 Windows 版 VS Code、WSL 扩展和目标发行版。在「设置」的「当前设备的 VS Code (WSL)」中保存发行版和 WSL 文件夹路径，从「连接」点击 VS Code 入口。如果浏览器询问是否打开外部应用，确认后由当前设备处理。所有浏览器共用这里保存的目标，换设备后可按需修改发行版和路径。
