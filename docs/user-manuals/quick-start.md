# workstation 用户手册（精简版）

当前可在本地用浏览器打开[网页版界面演示](../../demos/index.html)。以下是[首版](../../SPEC.md)部署后的操作速查。

- **登录**：在浏览器打开 workstation 地址，输入账号和密码。
- **管理文件**：进入「文件」，可浏览、上传、下载、重命名、删除和新建文件夹，也可预览图片、文本和视频。手机可通过浏览器上传文件到电脑。
- **连接电脑**：进入「连接」，下载 `.rdp` 文件，用远程桌面客户端打开。常用动作可在「设置」中配置，再回到「连接」触发。
- **打开 VS Code**：在已安装 VS Code 的设备上，进入「连接」并选择「VS Code (WSL)」。
