# workstation 用户手册（精简版）

本机服务已支持以下操作。远程桌面和公网访问仍在准备中。[本地启动](../exec-plans/completed/003-web-authentication.md)

- **登录和退出**：打开 workstation 地址，输入账号和密码。用完点击「退出登录」。
- **管理文件**：进入「文件」并选择磁盘。可上传、下载、重命名、删除、新建目录或预览图片、文本和视频。大文件用 Up2k 上传，可在同一目录重新选择原文件续传。
- **运行主机动作**：在「设置」添加主机预设，再从「连接」触发。没有预设时显示远程桌面入口，实际连接待接入。
- **打开当前设备的 VS Code**：在「设置」保存 WSL 目标，再从「连接」打开。当前设备需要 VS Code、WSL 扩展和对应发行版；换设备后可按需更新共享目标。
