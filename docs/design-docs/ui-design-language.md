# UI 设计语言（v1 定稿）

- 日期：2026-11-23
- 状态：已定稿（用户确认 demos v2）
- 来源：`demos/index.html`、`demos/android.html`（唯一实现依据；本文是决策记录，细节以实现为准）
- 设计原则来源：Apple Human Interface Guidelines（Motion / Layout），仅借鉴原则，不使用任何 Apple 资产（无 SF 字体文件、无 SF Symbols、无标志；图标为自绘 SVG，字体用系统字体栈）。

## 1. 视觉基调

- **浅色毛玻璃 + 极光背景**：底 `#f2f2f7`，其上三层径向渐变色块（蓝/紫/粉，blur 90px）缓慢漂移；Android 展台页用深色 + 同色极光。
- **材质**：卡片与侧栏用半透明白 + `backdrop-filter: saturate(180%) blur(20–32px)`，1px 半透白描边。
- **色彩**：正文 `#1d1d1f`，次要 `#6e6e73`，三级 `#9c9ca1`；强调蓝 `#0a84ff`，按钮渐变 `#2f96ff → #0a6cf0`；危险 `#ff453a`；演示徽标黄底、后续阶段徽标紫底。

## 2. 字级与排版

- 大标题 40px/700（窄屏 30px），页标题 21px/700，正文 15px，辅助 12.5–14px；字距收紧（letter-spacing 负值）。
- 布局：宽屏 Finder 式侧边栏（248px，毛玻璃）+ 内容列；≤860px 切换为底部悬浮胶囊标签栏。

## 3. 形状与组件

- 圆角：卡片 24px，行/输入框 13px，按钮与徽标全圆角（980px）。
- 按钮：渐变胶囊 + 内高光 + 投影；次级按钮白底描边。
- 图标瓦片：52px 圆角方块，渐变底（蓝/紫/橙区分功能）+ 内阴影高光。
- 弹层（Sheet）：中心缩放淡入 + 模糊遮罩，Esc/点击遮罩关闭。

## 4. 动效

- 缓动统一 `cubic-bezier(.32,.72,0,1)`（弹簧感）；时长 200–500ms。
- 页面进入 fadeUp；列表逐项渐入（stagger，每项延迟 45–60ms）；卡片悬停上浮 -3px + 阴影加深；按钮按压 scale(.96)。
- **可访问性**：`prefers-reduced-motion: reduce` 时全部动画/漂移降为瞬变。

## 5. 演示完整性规则

- 未接后端的行为只用 Toast/徽标标注「演示」，不伪造成功提示；预览内容标注为占位数据。
